# output 输出接口约定

本目录是系统的输出层, 供"下一个模块"对接。当前系统产出的所有关键事件都经 `bridge.py` 的 `forward(event_type, payload)` 透传。

## 对接方式

1. **读文件**: `forward()` 每次会在 `output/outbox/` 落一个 JSON 文件, 文件名 = `时间_事件类型.json`;
2. **收推送**: 启动服务前设置环境变量 `NEXT_MODULE_ENDPOINT=http://你的地址/xxx`, 每条产出会实时 POST 到该地址;
3. **直接调函数**: 下一模块若是 Python, 可 `from output.bridge import forward` 复用。

## 事件类型与载荷

| event | 触发时机 | payload 主要字段 |
|---|---|---|
| triage | 智能导诊出结果 | dept(科室), alternatives(备选科室), exam_prep(检查须知), suggestion |
| journey | 就诊流程卡生成/步骤推进 | dept, steps(全部步骤), current_step, done_keys |
| route | 导航路线生成 | start, end, distance_m, segments(分楼层像素坐标), steps(指引文字) |
| chat | AI 对话一轮 | session_id, user_message, reply, step(当前流程步骤) |
| registration | 挂号演示成功 | registration_id, patient_name, doctor, dept, visit_date, slot |

载荷里的坐标是 1200x800 平面图像素坐标; segments 按楼层顺序排列, 换乘点在 steps 的 kind 字段(elev/stair/escalator)标明。

## 约定

- 事件格式稳定后不改字段名, 只增不减;
- outbox 文件保留 7 天, 之后由下一模块自行清理或归档;
- 下一模块的入口地址通过 `NEXT_MODULE_ENDPOINT` 配置, 不写死在代码里。
